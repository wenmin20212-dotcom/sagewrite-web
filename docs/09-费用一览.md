# 9. 费用一览

**人民币 1 元 ＝ 100 积分。** 以下为当前规则，如有调整以网站显示为准。

## 9.1 免费功能

- 新建书籍、编辑目录、手工写作、保存、导出正文 Markdown
- 快速检查
- 一键成书（Word / EPUB / PDF）及分步构建
- 生成和修改有声书朗读稿、读法表
- 有声书整章合成、视频「拼成整章视频」
- 视频2（解说动画）——目前免费
- 插图核查后的重新出图（不含核查本身）
- 进度图人工确认、工作台标识、书库分类

## 9.2 固定价格

| 功能 | 价格 | 何时扣 |
| --- | --- | --- |
| 自动制作封面 | 200 积分 / 张 | 成功交付后 |
| 有声书 | 每千字 30 积分（按朗读稿字数） | 每节通过成品检查后 |
| 视频（配图 + 字幕） | 150 积分 / 节 | 每节通过成品检查后 |
| 重做一张视频配图 | 30 积分 / 张 | 重做成功后 |

失败、停止、超时**都不扣**。同一任务的同一项只扣一次；主动“重新生成”属于新任务，会再扣。

## 9.3 按 AI 用量计费

以下功能按每次 AI 调用实际的**输入 / 输出 token**（可粗略理解为 AI 读进和写出的文字量）计费：

- 生成目录、写作、扩展、修饰、审稿、翻译
- 按意思查重、事实核查（含图中文字核查）
- 插图制作

计算方法（当前费率）：

```text
估算成本（美元）= 输入 token × 2 ÷ 1,000,000 + 输出 token × 10 ÷ 1,000,000
扣除积分 = 估算成本 × 7.2（汇率）× 1.2 × 100
```

约等于：**每 1,000 输入 token ≈ 1.73 积分，每 1,000 输出 token ≈ 8.64 积分**。

例：输入 1,000、输出 500 token → 扣约 6.05 积分。

事实核查勾选「联网查证」时，每次网页搜索另计约 **8.64 积分**，搜索带回的内容按输入 token 计费。

### 参考实例

以下是在一本约 10 万字书稿上的实测，仅供估算：

| 操作 | 约用积分 |
| --- | --- |
| 按意思查重（全书一次） | 约 157 |
| 事实核查，不联网（260 句） | 约 46 |
| 事实核查，联网（260 句，搜索 40 次） | 约 1,001 |
| 有声书（8 万字全书） | 约 2,400 |

## 9.4 其他说明

- 一个任务可能调用 AI 多次，逐次计费；任务中途失败或停止，已发生的调用费用不退回。
- 余额不足时目前**不阻止**使用，余额可能为负，充值后补上。
- 每一笔扣费都会记在「我的账号 → 积分流水」中，可以随时核对。
