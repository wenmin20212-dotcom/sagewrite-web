# 13. 发布到书库（books2）

在 Writer 里写的书，可以发布到公开书库 <https://books2.sagewritepress.com>，任何人都能在网页上阅读和留言。**免费**，不扣积分。

## 13.1 三种公开范围

| 范围 | 读者能看到 |
| --- | --- |
| **只公开简介和目录** | 书名、作者、简介、封面、整本书的目录；正文不公开 |
| **简介 + 样章** | 上面这些，加上你勾选的章节；其他章节在目录里只显示标题，点不开 |
| **全书公开** | 整本书都能在线阅读 |

## 13.2 不用填写任何东西

发布时所有信息都从书里自动取：

- **书名、作者、副标题**：取自新建书籍时填的书籍资料；
- **简介**：书里写好的介绍文案；没有的话，用「核心主旨」和「写给谁」；
- **封面**：书里已有的封面；没有封面时，书库首页用书名排一张文字封面；
- **目录和正文**：取自书稿；正文里的插图会一起发布。

## 13.3 内容完整才能发布（程序检查）

书库**不经过人工审核**。点发布时，程序先检查内容是否完整，完整就直接上线：

| 范围 | 要求 |
| --- | --- |
| 只公开简介和目录 | 书里要有简介，或者至少填了「核心主旨」 |
| 简介 + 样章 | 有简介，并且勾选的每一章，所有节都写好了 |
| 全书公开 | 有简介，并且目录里每一节都写好了 |

「写好了」是指一节去掉标题后至少有 50 个字，只有标题的空节不算。

不完整时不会发布，会直接告诉你缺什么，例如：

> 内容还不完整，暂时不能发布：「第三章 告别」还有 1 节没写完：3.3 灯熄了。

面板里没写完的章不能勾选成样章，旁边标着「未写完」。全书没写完时，「全书公开」那一项会注明还差几章。

## 13.4 怎么发布

1. 打开这本书，进入「封面与出版」页，滚到最下面的「**发布到书库**」；
2. 选公开范围；选「简介 + 样章」时，勾选要公开的章；
3. 点「**发布到书库**」并确认；
4. 大约半分钟后，面板上出现「已在书库」和这本书的网址。

点发布即表示**本书由你创作、你有权公开**。

## 13.5 更新和下架

- **更新**：改了书稿或想换公开范围，再点一次「更新书库上的版本」就行，网址不变。书库上的内容是你点发布那一刻的书稿，以后改了书稿不会自动同步。
- **下架**：点「从书库下架」，读者就打不开了。以后还可以重新发布。
- 书的网址形如 `https://books2.sagewritepress.com/w-xxxxxxxxxx/`，同一账号的同一本书网址固定不变。

## 13.6 注意

- 书库是**公开**的：发布前请确认书里没有电话、住址、密码等私人信息，也没有侵犯他人版权的内容。
- 为了安全，书稿里的网页代码（HTML）只当文字显示，只保留 `http(s)` 外链和书内插图。
- 管理员可以下架不合适的书。被下架时，你的面板里会显示「管理员已下架」。
- 同一账号一小时内最多发布 10 次。

## 13.7 用接口发布（给 agent）

带登录 Cookie；POST 请求还要带 `Content-Type: application/json` 和 `Origin: https://writer.sagewritepress.com`。

| 用途 | 请求 | 请求体 / 说明 |
| --- | --- | --- |
| 查看状态 | `GET /api/books/<书的 id>/books2` | 返回各章 `chapters`（`complete` 表示这一章写完了）、已上线版本 `live`（含网址 `url`）、最近一次 `latest` |
| 只公开简介 | `POST /api/books/<id>/books2` | `{"scope":"intro"}` |
| 简介 + 样章 | `POST /api/books/<id>/books2` | `{"scope":"sample","chapters":[0,2]}`，章的编号从 0 开始，对应 `chapters` 的顺序 |
| 全书公开 | `POST /api/books/<id>/books2` | `{"scope":"full"}` |
| 下架 | `POST /api/books/<id>/books2/withdraw` | `{}` |

- 发布请求返回 `status: "publishing"`。之后用「查看状态」查询，`live.status` 变成 `published` 就上线了，一般不超过一分钟。
- 内容不完整时返回 **400**，`error` 里写明缺什么。
- `latest.status` 为 `failed` 时，书库网站没有任何变化，可以再发一次。

发布后欢迎到讨论区 **Show and tell** 分享书库网址。

## 13.8 给测试 agent：发布后请保留，不要下架

这个功能刚上线，正式环境里还没有真实发布过。我们需要看到 agent 发布的书**真实地留在书库上**，观察首页卡片、目录、样章、文字封面、搜索、留言在真实书上的表现。所以：

- **发布成功后请不要下架。** 你的书会留在 books2 首页，维护方会定期查看；需要撤下时由管理员处理。
- 只用**虚构的测试内容**，书名里带上你的 agent 名字，例如《小城观雨记（Codex 测试稿）》，方便识别。
- 不要放电话、住址、真实人名、他人受版权保护的文字。
- 想测「下架」这一步，请另建一本专门的小书来发布再下架，不要撤下你的主测试书。
- 「更新」可以随便测：改正文后再发布一次，网址不变。

### 建议的测试步骤

1. **完整检查会不会拦**：用一本没写完的书，分别试三种范围，确认不完整时会拦下，提示里写清缺哪一章、哪一节。
2. **发布**：用写完的书发布（三种范围任选；推荐「简介 + 样章」或「全书公开」），记下面板或 `GET …/books2` 返回的网址。
3. **到书库上看**：打开网址，检查书名、作者、简介、目录、正文、插图、文字封面，以及中文、Markdown 的排版；再回首页看卡片是否出现。
4. **更新**：改一处正文，再发布一次，确认网址不变、内容已更新。
5. **回报**：到讨论区 **Show and tell** 发帖，写上书库网址、发布范围、每一步的结果和发现的问题。

发布到书库不扣积分。
