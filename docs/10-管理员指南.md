# 10. 管理员指南

管理员登录后，在「我的账号」页面会看到「用户账号」和「微信充值审核」两个区域（即「账号管理」）。普通用户看不到这些功能。

## 10.1 创建普通用户（为他人开账号）

1. 「用户账号」→ 点「**创建普通用户**」。
2. 填写：
   - **账号名称**：用户登录用的名字；
   - **登录密码**：至少 12 个字符，输入两次。
3. 点「保存账号」。
4. 通过**可信方式**（当面、私信）把账号名称和密码交给使用者，并提醒对方登录后立即修改密码。

系统不会发送邮件。管理员建的账号积分为 0，拥有独立、空白的书库。

> 用户也可以在登录页自助注册。自助注册的账号在列表中显示为「普通用户（自助注册）」，自动获得 300 试用积分，积分用完后收费功能暂停；管理员建的账号不受这条限制。

## 10.2 管理已有账号

「用户账号」表格列出每个账号的名称、邮箱 / 手机、积分、身份、状态。每行「操作」中可以：

| 操作 | 说明 |
| --- | --- |
| 修改资料 | 修改称呼、邮箱、手机 |
| 重设密码 | 为忘记密码的用户设置新密码；该用户所有旧登录立即失效 |
| 停用 / 启用 | 停用后用户无法登录，现有登录立即失效；书稿和积分保留 |
| 调整积分 | 赠送或纠错，见下文 |
| 积分记录 | 查看该用户的积分流水和订单 |

## 10.3 调整积分

「调整积分」**仅用于赠送或纠错**，不代表收到了充值付款。

1. 填写积分变动：增加为正数，扣减为负数；
2. 填写**原因**（必填）；
3. 点「记入积分流水」。

每笔调整都会记录操作的管理员、原因和时间。

## 10.4 审核微信充值

用户付款并提交申请后，申请会出现在「微信充值审核」中。

1. 点「刷新申请」，查看账号、订单、金额、付款说明。
2. **打开微信，亲自核对实际到账金额和交易单号。**
3. 点该申请的「核实到账」：
   - 填写**微信实际到账金额（元）**；
   - 填写**微信实际交易单号**（必填，不能与其他订单重复）；
   - 勾选「我已在微信核实这笔实际到账」；
   - 点「确认到账并加积分」，系统按 1 元 ＝ 100 积分入账。
4. 如果没有收到款项，填写「未通过原因」，点「确认未通过」。

安全设计：

- 用户提交申请**不会**自动加积分；
- 同一订单重复确认不会重复加分；
- 同一个微信交易单号不能给多个订单入账。

## 10.5 管理员注意事项

- 请不要把账号密码发在公开群聊或公开页面。
- 积分调整和充值确认都会留下记录，无法“悄悄”修改余额。
