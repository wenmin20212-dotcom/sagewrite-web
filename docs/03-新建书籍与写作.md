# 3. 新建书籍与手工写作

## 3.1 工作台

登录后首先看到「工作台」：

- **继续写作**：回到最近编辑的书和章节；
- **你的书架**：最近的几本书，点「查看全部 →」进入「我的书库」；
- **＋ 新建书籍**：开始一本新书。

## 3.2 新建书籍

点「＋ 新建书籍」，填写：

| 字段 | 说明 |
| --- | --- |
| 书名 | 必填 |
| 一句话介绍 | 这本书讲什么 |
| 作者署名 | 印在封面和成品上的名字 |
| 写给谁 | 目标读者 |
| 核心主旨 | 全书想表达的核心观点 |
| 内容范围 | 包含哪些、不包含哪些 |
| 写作风格 | 例如通俗、学术、故事化 |

点「创建书籍」。除书名外都可以以后再补；但这些资料会被 AI 写作、自动封面等功能使用，**写得越清楚，AI 的结果越贴切**。进度图的第 1 步“基本信息”要求读者、范围、风格都填写。

## 3.3 我的书库

「我的书库」列出你所有的书，按最近更新排序，可以搜索书名、按分类筛选，并查看统计。可以给书设置分类（单本或批量），只影响书库显示，不改动书稿。

## 3.4 目录

书的结构是：**目录（章 / 节）→ 正文单元**。每个正文单元对应目录中的一个小节。

在「章节写作」页：

- **编辑目录**：手工修改章节标题和层级；
- **生成目录**：让 AI 按书籍资料生成目录（扣积分，见第 4 章）；
- **＋ 添加章节**：新增一个正文单元并命名。

## 3.5 选择章节

点「选择章节」按钮，可以按标题、编号搜索并跳转。按钮上显示当前章节和总数。电脑上左侧还会显示完整目录；手机上目录收起，选中后直接进入正文。

## 3.6 写作与保存

- 在正文编辑区直接写作，支持 Markdown 格式（# 标题、**加粗**、列表等）。
- 右侧“写作辅助”显示当前章节字数。
- **保存**：点「保存书稿」，或在 Mac 电脑上按 **Command+S**。手机上使用页面上的保存按钮。
- 切换章节前会先保存；保存失败时不会切换，避免丢稿。
- 每次保存前，系统会在书内自动留一份备份。

> 目前**没有持续自动保存**，也不支持离线写作。长时间写作请经常保存，尤其是在手机上。

## 3.7 保存时提示“版本冲突”

说明这一章在别的窗口或设备上已经被修改并保存过。请：

1. 先把你当前的文字**复制到别处**保留；
2. 刷新页面，查看最新内容；
3. 手工合并后再保存。

不要直接覆盖，否则会丢掉另一边的修改。系统不支持多人同时编辑同一章的实时合并。

## 3.8 任务进行中不能编辑

同一本书有未结束的 AI 任务（如写作、查重）时，编辑和保存会被暂时锁定，以免和任务的写入冲突。任务完成或在「任务中心」停止后即可继续编辑。

（有声书和视频生成**不会**锁定书稿，生成期间可以照常写作。）

## 3.9 导出正文

「封面与出版」页可以「下载正文 Markdown」，把整本书的正文导出为一个文件，方便备份或在其他编辑器中使用。
