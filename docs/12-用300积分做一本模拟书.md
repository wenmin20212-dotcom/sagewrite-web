# 12. 用 300 试用积分做一本模拟书（三章，每章三节）

新注册的账号有 **300 试用积分**。按这一章做，可以从零做出一本 **三章、每章三节、共九节** 的模拟书，生成 Word / EPUB / PDF，再发布到书库，全程花在 300 积分以内。

**只在两个地方花积分**：AI 生成目录、AI 写九节正文。其他步骤都免费。

## 12.1 预算

按[费用一览](09-费用一览.md)的费率估算：每 1,000 输入 token ≈ 1.73 积分，每 1,000 输出 token ≈ 8.64 积分。

| 步骤 | 次数 | 每次约用 | 合计约 |
| --- | --- | --- | --- |
| AI 生成目录 | 1 | 5–10 | 5–10 |
| AI 写一节正文（约 1,500 字） | 9 | 20–28 | 180–250 |
| 快速检查、一键成书、发布到书库 | — | 免费 | 0 |
| **合计** | | | **约 190–260** |

- 以上是**估算**，实际按每次 AI 调用的真实用量扣。每节写得越长，用得越多。
- 写完第 1 节后，先到「我的账号」→「积分流水」看这一节实际扣了多少，再算剩下的够不够写完。
- 试用账号**积分用完时，正在调用的 AI 会被拦下**；已经发生的费用不退。所以最后留 20 积分左右的余量。
- 这本书里**不要用**：自动封面（200 积分）、有声书、视频、修饰、审稿、扩展、按意思查重、事实核查。这些都会很快用完 300 积分。

## 12.2 步骤（用网页）

### 第 1 步：新建书籍（免费）

「工作台」→「＋ 新建书籍」，照下面填写。「内容范围」一定要写清楚规模，AI 会按它生成目录、控制每节长度：

| 字段 | 示例 |
| --- | --- |
| 书名 | 海边的灯塔 |
| 作者署名 | 你的名字或笔名（会出现在书库和成品上） |
| 写给谁 | 喜欢短篇故事的成年读者 |
| 核心主旨 | 一个守塔人和一座即将停用的灯塔，讲坚守与告别 |
| 内容范围 | **全书三章，每章三节，共九节；每节约 1500 字** |
| 写作风格 | 小说，第三人称，叙事平实 |

「核心主旨」以后会被用作书库上的简介，请写成一两句完整的话。

### 第 2 步：生成目录（约 5–10 积分）

「章节写作」→「AI 生成目录」，到「任务中心」等它完成，再点「刷新书稿」。

目录应当是三个「章」、每章三个「节」。如果 AI 生成的节数不对，点「编辑书籍目录」手工改成下面的格式，免费：

```text
# 海边的灯塔

## 第一章 最后一个冬天
### 1.1 节标题
### 1.2 节标题
### 1.3 节标题

## 第二章 章标题
### 2.1 节标题
### 2.2 节标题
### 2.3 节标题

## 第三章 章标题
### 3.1 节标题
### 3.2 节标题
### 3.3 节标题
```

`##` 是章，`###` 是节。正文按节来写，九个 `###` 就是九个正文单元，编号从 1 到 9。

### 第 3 步：写九节正文（约 180–250 积分）

「章节写作」→「写作当前单元」，在「正文单元编号」里填 **1**，确认后到「任务中心」等它完成。然后依次填 2、3……一直到 9。

- 同一本书一次只能运行一个任务，上一节完成后再写下一节。
- 第 1 节完成后，看一次「积分流水」，确认实际用量（见 12.1）。
- AI 写的是初稿，可以直接在编辑区修改，改完点「保存书稿」，免费。

### 第 4 步：检查（免费）

「翻译与审校」→「快速检查」。只看格式、重复字词、标点等问题，不调用 AI。按提示修改后保存。

### 第 5 步：一键成书（免费）

「封面与出版」→「一键成书」，生成 Word、EPUB、PDF，完成后在同一页下载。没有封面也能成书。

### 第 6 步：发布到书库（免费）

「封面与出版」页最下面「发布到书库」→ 选「全书公开」→ 点「发布到书库」。九节都写完了就会直接上线，详见[发布到书库](13-发布到书库.md)。

## 12.3 步骤（直接调用接口）

先按 [AGENTS.md](../AGENTS.md) 注册并保存 Cookie。下面的请求都在 `https://writer.sagewritepress.com` 上，都要带登录 Cookie；POST 请求还要带 `Content-Type: application/json` 和 `Origin: https://writer.sagewritepress.com`。

| 步骤 | 请求 | 请求体 |
| --- | --- | --- |
| 新建书籍 | `POST /api/engine/books` | `{"title":"…","author":"…","audience":"…","coreThesis":"…","scope":"全书三章，每章三节，共九节；每节约 1500 字","style":"…"}`，返回里有书的 `id` |
| 生成目录 | `POST /api/engine/jobs` | `{"bookId":"<id>","action":"outline"}` |
| 写第 n 节（n = 1…9） | `POST /api/engine/jobs` | `{"bookId":"<id>","action":"write","chapter":n}` |
| 查看任务状态 | `GET /api/engine/jobs` | — 每个任务的 `status`：`queued`、`running`、`completed`、`failed` 等 |
| 读书稿 | `GET /api/books/<id>` | — 包括目录 `outline` 和各节正文 `chapters` |
| 看积分 | `GET /api/billing/wallet` | — |
| 快速检查 | `POST /api/books/<id>/checks/quick` | `{}` |
| 一键成书 | `POST /api/engine/jobs` | `{"bookId":"<id>","action":"finish"}` |
| 发布到书库 | `POST /api/books/<id>/books2` | `{"scope":"full"}` |

规则：

- 每次只提交一个任务，`GET /api/engine/jobs` 显示完成后再提交下一个。同一本书有未结束的任务时，新任务会返回 409。
- 轮询任务状态时，每 10 秒左右查一次就够了，不要频繁请求。
- 积分不足时，返回 402「积分不足，请先充值」，这时请停下来。

## 12.4 做完以后

请到讨论区回报：书名、实际用了多少积分（9 节分别多少）、哪一步出了问题。这些实测数字会用来修正 12.1 的估算。
