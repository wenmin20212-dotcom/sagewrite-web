# 1. 开通账号与登录

## 1.1 如何开通账号

SageWrite Web **目前不开放公开注册**，也没有邮箱或短信验证。开通方式是：

1. **联系 SageWrite 管理员**，说明你想使用 SageWrite Web 写书。
2. 管理员在后台「账号管理 → 创建普通用户」为你建立账号，设置：
   - **账号名称**（登录用的名字）；
   - **初始登录密码**（至少 12 个字符）。
3. 管理员通过可信的方式（当面、私信等）把账号名称和初始密码交给你。系统**不会自动发邮件**。
4. 新账号的积分余额从 0 开始；需要使用扣积分的功能时，按 [充值流程](02-我的账号与积分充值.md#24-充值微信收款码) 充值，或由管理员赠送。

> 管理员的具体操作见 [管理员指南](10-管理员指南.md)。

## 1.2 第一次登录

1. 打开 <https://writer.sagewritepress.com>，看到「登录写作工作台」页面。
2. 输入 **账号** 和 **密码**，点「登录」。
3. 登录成功后进入「工作台」。新账号的书库是空的，这是正常的——你只会看到自己的书。

登录后同一台设备会**保持登录 30 天**。在网吧、公用电脑等公共设备上使用后，请务必点「退出登录」。

## 1.3 第一次登录后建议立刻做的事

1. 进入「我的账号」（工作台右上角或菜单里）。
2. 在「修改自己的密码」中：
   - 输入当前密码（管理员给你的初始密码）；
   - 输入新密码两次（**至少 12 个字符**）；
   - 点「保存新密码」。
3. 在「基本信息」中填写称呼、邮箱、手机（含国际区号，如 +86、+60），点「保存基本信息」。

> 邮箱和手机只是方便管理员联系你，**不用于登录，也不能用来找回密码**。

## 1.4 修改密码

「我的账号 → 修改自己的密码」。修改后：

- **其他设备会自动退出登录**；
- 当前设备重新保持登录 30 天。

## 1.5 忘记密码怎么办

网站没有“忘记密码”自助找回。请联系管理员，管理员可以为你**重设密码**；重设后你所有设备上的旧登录都会失效，用新密码重新登录即可，书稿和积分不受影响。

## 1.6 退出登录

「我的账号」页面右上角点「退出登录」。

## 1.7 什么情况下需要重新登录

- 超过 30 天没有登录；
- 你自己改了密码（其他设备）；
- 管理员重设了你的密码或停用了你的账号；
- 浏览器清除了网站数据（Cookie）。

如果账号被停用，登录会失败，请联系管理员。
