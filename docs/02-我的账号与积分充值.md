# 2. 我的账号、积分与充值

入口：登录后点「我的账号」。

## 2.1 基本信息

可填写 **称呼、邮箱、手机（含国际区号）**，点「保存基本信息」。这些只是联系资料，不参与登录。

## 2.2 我的工作台标识

可从 8 个内置图案中选一个，显示在工作台左上角：钢笔、毛笔、鹅毛笔、铅笔、打开的书、书卷、打字机、墨水瓶。选好后点「保存标识」。免费更换，电脑和手机同步显示，重新登录后仍然保留。

## 2.3 积分是什么

部分功能（AI 写作与检查、自动封面、有声书、视频等）会扣积分，规则见 [费用一览](09-费用一览.md)。

- **人民币 1 元 ＝ 100 积分**。
- 「我的积分」显示当前余额。
- 「积分流水」逐笔列出每次变动：时间、变动额、变动后余额、说明（例如“有声书 · 书名 节名 · 字数”）。
- 目前余额不足时**不会阻止**你使用功能，余额可能变成负数；之后充值即可补上。

## 2.4 充值（微信收款码）

目前采用 **微信收款码 + 管理员人工核实** 的方式，没有自动到账。每笔订单金额 **1—100 元**。

### 步骤

1. 在「我的积分」中输入**充值金额（人民币元）**，支付方式选**微信**，点「生成订单并显示收款码」（按钮文字可能显示为「生成充值订单」）。页面会显示可得积分（例：10 元 = 1,000 积分）。
2. 在弹出的「微信收款码」窗口中（关掉后可在「充值订单」中点「显示收款码 / 去付款」重新打开），核对收款人，**按订单金额**付款：
   - 电脑上：用手机微信扫一扫；
   - 只有一部手机：点「保存收款码」把图片存到相册，再在微信「扫一扫」里从相册选择这张图。
3. 付款完成后回到网页，填写**付款说明**（付款人微信名、付款时间等），微信交易单号可选填，点「**我已付款，提交审核**」。
4. 等待管理员在微信核实实际到账。核实后积分自动加到你的账户，「积分流水」中会出现一条充值记录。

### 注意

- **生成订单、提交申请都不会立即加积分**，以管理员核实为准。
- 付款金额请与订单金额一致；金额不一致时，管理员按**实际到账金额**入账。
- 还没付款的订单可以点「取消订单」；已提交审核的订单不能自己取消。
- 每个账号最多同时有 20 个未完成订单。
- 如果管理员核实未收到款项，订单会被标为“未通过”并注明原因。
- 支付宝渠道**暂未开通**，请不要使用。

## 2.5 查看订单和刷新

「充值订单」列出你所有订单的时间、金额、积分、方式和状态。点「刷新余额与订单」可查看最新审核结果。
