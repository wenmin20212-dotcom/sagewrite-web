# 4. AI 写作与任务中心

SageWrite 的 AI 功能都以“任务”的形式在后台运行：点开始后，可以继续做别的事，到「任务中心」查看结果。

## 4.1 AI 写作功能

| 功能 | 位置 | 作用 |
| --- | --- | --- |
| 生成目录 | 章节写作 | 按书籍资料生成章节目录 |
| 写作当前单元 / AI 续写 | 章节写作 | 按目录和上下文写出这一节正文 |
| 扩展小节 | 章节写作 | 把较短的小节扩写得更充实 |
| 修饰当前单元 / 修饰选定单元 | 章节写作 | 调整表达、润色文字 |
| 审稿选定单元 | 翻译与审校 | 对选定的单元给出审稿意见 |
| 翻译选定单元 | 翻译与审校 | 选择**目标语言**，把选定单元译成译本 |

使用方法：选好书和单元，点相应按钮，确认后任务开始。

**费用**：这些功能按 AI 实际用量（输入 / 输出字数折算的 token）扣积分，详见 [费用一览](09-费用一览.md)。一个任务可能调用 AI 多次，每次分别计费；任务中途失败或被停止，已经发生的调用费用不退回。

## 4.2 任务中心

「任务中心」列出你的所有任务：

- **状态**：排队中、运行中、已完成、失败、已停止、等待助手等；
- **日志**：点开可以看到任务每一步做了什么、出了什么错；
- **停止任务**：运行中的任务可以随时停止，已生成的内容会保留。

判断任务是否成功，请以**任务日志和实际生成的内容**为准——点“开始”不代表已经完成。

同一账号最多同时运行 2 个任务。任务有超时限制，超时会自动结束并显示失败。

## 4.3 “等待助手”与助手接力

极少数任务会显示“等待助手”。这时可以点「打开助手接力」，查看接力请求，把助手给出的结果粘贴进来，点「保存接力结果」，再点续接继续任务。一般用户很少遇到；如不清楚，请联系管理员。

## 4.4 使用建议

- AI 写出的内容是**初稿**，请务必通读修改，尤其是事实、数字、引用和人名。
- 先把书籍资料（读者、主旨、范围、风格）填清楚，再用 AI，效果更好。
- 大段生成前可以先在一两个小节上试用，满意后再推广到全书。
