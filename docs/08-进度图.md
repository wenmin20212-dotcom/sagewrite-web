# 8. 每本书的进度图

打开一本书后，「章节写作」「翻译与审校」「封面与出版」页面上方会显示这本书的 **8 步彩色进度图**。

## 8.1 八个步骤

| 步骤 | 什么时候算完成 |
| --- | --- |
| 1. 基本信息 | 书名、读者、范围、风格都已填写 |
| 2. 目录设计 | 目录中已有小节 |
| 3. 正文写作 | 目录中的每一节都有非空正文（显示“已填写 N / 共 M 节”） |
| 4. 内容检查 | 当前版本已做快速检查、按意思查重、事实核查，且问题都已处理 |
| 5. 插图制作 | 插图已插入正文，并已核查图中文字 |
| 6. 封面制作 | 封面已就位 |
| 7. 成书构建 | 在最近一次修改之后已生成 Word、EPUB、PDF |
| 8. 交付归档 | 不会自动完成，实际交付后由你手动确认并填写交付位置 |

## 8.2 颜色含义

| 显示 | 含义 |
| --- | --- |
| 绿色 ✓ | 已完成 |
| 灰色 ○ | 未完成 |
| 蓝色 ↻ | 进行中（有任务在运行） |
| 橙色 ! | 需处理（任务失败、成品过期等） |
| 浅紫斜纹 — | 无需此项 |

上方汇总“已完成 X / Y 步”，“无需此项”不计入总数。

## 8.3 查看详情与人工确认

点任意一步，可以看到完成依据或未完成原因，并跳到对应页面。也可以**人工确认**状态（未完成、进行中、已完成、需处理、无需此项）并写说明，例如某本书不需要插图就选“无需此项”。

- 人工确认不会运行任何功能，也不扣积分。
- 相关内容改动后，原来的人工确认会失效，提示你重新核对。

> 进度图反映的是“步骤是否做过”，**不代表内容质量已经达标**。
