# 6. 封面与出版

入口：打开一本书，进入「封面与出版」。

## 6.1 自动制作封面（200 积分）

1. 选择封面语言（有译本时可选）。
2. 点「**自动制作封面 · 200积分**」。
3. AI 根据书籍资料和目录理解主题，生成一张无文字的竖版底图；系统再把**书名、副题、作者**排上去，检查尺寸和文字边界，然后应用为这本书的封面。
4. 制作约需几分钟。完成后封面显示在书库和出版页。

计费规则：

- **成功交付才扣 200 积分**；失败或取消不扣。
- 重复点击不会重复扣分；不满意可以**重新制作**，成功后再扣 200。
- 旧封面会保留，可以「下载此版封面」；目前网页上还没有“换回旧封面”的按钮。
- 更换封面后，已经生成的 Word / EPUB / PDF 不会自动更新，需要重新一键成书。
- 目前只制作**电子书正封面**，不含印刷版的封底、书脊和出血。
- 全站一次只制作一张封面，人多时需要排队。

## 6.2 一键成书（免费）

入口：「封面与出版」→「一键成书」。不调用 AI，**不扣积分**。

系统依次：

1. 备份正文和目录；
2. 统一正文格式并做格式检查——**不通过就停下并列出问题**，请按提示修改后重试；
3. 生成 **Word（.docx）**；
4. 生成 **EPUB** 电子书；
5. 生成 **A4 PDF**（带封面页）。

开始前，确认框会提醒你还没完成的检查（例如没做快速检查、核查还有未处理条目、没有封面），只提醒、不阻止。

说明：

- 只生成简体中文正文的成书，不含译本。
- 格式统一会按系统规则调整正文格式，调整前有备份。
- PDF 排版没有逐页人工验收，正式发布前请自己翻看一遍。

## 6.3 分步构建（进阶）

「运行格式检查」「正式文档构建」等按钮可以单独运行某一步，适合熟悉流程的用户。一般用户直接用「一键成书」即可。

## 6.4 下载成品

「封面与出版」下方的成品列表列出这本书已有的 PDF、Word、EPUB 等文件，点「下载」即可。构建完成后如果列表没更新，请刷新页面。

> 成品列表不会自动判断哪个是“最新版”。正文修改后，请重新一键成书，以免下载到旧版本（进度图第 7 步会提示成品是否过期）。
